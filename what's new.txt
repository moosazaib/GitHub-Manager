* Create New Folders Directly: You can now create new folders inside your repository via 'More Options'. If a folder already exists, the app displays "Folder Already Exist" and returns to the options window.

* View Public Repositories: Added a 'View Public Repositories' button to public profiles, allowing you to search and view all public repositories of that user.
